# DES 加密算法实现

本项目使用 Python 实现了数据加密标准 (DES) 算法。项目采用模块化设计，为了清晰和教学目的，将 DES 算法的每一步（置换、S-Box、密钥调度等）都实现在单独的文件中。

## 项目结构

项目组织为以下模块化组件：

- **核心组件：**
  - `ip_sub.py`: 处理初始置换 (IP) 和逆初始置换 ($IP^{-1}$)。
  - `pc_.py`: 实现用于密钥调度和子密钥生成的置换选择 1 (PC-1) 和置换选择 2 (PC-2)。
  - `e_expend.py`: 执行 E-扩展置换（32位到48位）。
  - `s_box_sub.py`: 包含 S-Box 定义和替换逻辑。
  - `p_box.py`: 实现 P-Box 置换。
  - `xor_R.py`: XOR 运算的辅助函数。

- **主要脚本：**
  - `1_epoch_des.py`: 演示 DES 加密的 **单轮** 过程，提供详细的分步输出。对于调试或通过内部状态变化来理解算法非常有用。
  - `complete_des.py`: 实现完整的 **16轮** DES 加密算法。

## 使用说明

### 单轮演示

查看单个 DES 轮次（默认为第1轮）的详细输出：

```bash
python 1_epoch_des.py
```

这将输出每一步后的数据状态：
1.  明文转二进制
2.  初始置换 (IP)
3.  子密钥生成 (K1)
4.  E-扩展
5.  与子密钥进行 XOR
6.  S-Box 替换
7.  P-Box 置换
8.  计算 L1 和 R1

### 完整加密

运行完整的 16 轮 DES 加密：

```bash
python complete_des.py
```

您可以查看 `complete_des.py` 以了解如何迭代 16 个轮次以及如何生成最终的密文。

## 示例

**输入：**
- 明文：`FEFEFEFEFEFEFEFE`
- 密钥：`55555555555555`

**输出：**
- 脚本将打印中间和最终的十六进制值以供验证。
